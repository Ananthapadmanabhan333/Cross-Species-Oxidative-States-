Cross-species network discovery · technical report · 3 November 2026

Defence networks of Deinococcus radiodurans and humans

A reproducible comparison of two protein networks in the radiation-resistant bacterium D. radiodurans (NCBI taxon 1299; STRING strain R1, taxon 243230) and Homo sapiens (9606): oxidative-stress defence and DNA repair. The aim is to find candidate proteins with analogous functional roles, and to say how strong the evidence for each one is.

Prepared for Prof. Pietro Hiram Guzzi Author Ananthapadmanabhan Code github.com/Ananthapadmanabhan333/Cross-Species-Oxidative-States- @ 611d14f

All results are computational. None of them demonstrates biological equivalence or experimental validity.

Summary

Oxidative stress

Same reaction, different enzyme families

The strongest analogue candidates are superoxide dismutases. Bacterial Mn/Fe-SOD sodA pairs with human Cu/Zn SOD3 (rank 19) and SOD1; the bacterial Cu/Zn SODs pair with human Mn-SOD2. No homology is detected at any level for these pairs.

DNA repair

Convergent DNA glycosylases

Bacterial mutM (Fpg) pairs with human OGG1 and NTHL1, and nth pairs with NEIL1/NEIL3. Each pair removes oxidised DNA bases with unrelated folds. The pipeline found this textbook example of convergence from the data alone.

Topology adds little evidence

Network alignment conserves no more edges than degree-preserving random graphs when it uses topology alone. Conservation appears only when the alignment is anchored on sequence homologs, and STRING partly builds that in. Embeddings did not beat neighbourhood baselines.

Mutant data contradict some annotations

Published D. radiodurans mutants show that MnSOD is dispensable for radiation survival, that lexA deletion leaves DNA repair intact, and that pprA loss mainly affects cell division. The ranking records each of these as contradictory evidence.

Data and method

Seed proteins. Each process is defined by Gene Ontology annotation in UniProtKB: GO:0006979, GO:0098869 and GO:0016209 for oxidative stress, and GO:0006281 for DNA repair. Human seeds are Swiss-Prot entries only; D. radiodurans seeds include unreviewed entries, because only about 526 of its 3,104 entries are reviewed.

Networks. STRING 12.5 functional associations are downloaded at combined score ≥ 0.4 and analysed at 0.7. Every record passes QC, and each exclusion is logged with a reason. All raw responses are cached with SHA-256 checksums, so every run is reproducible offline.

Evidence for each protein pair comes from eight components:

  • Shared catalytic activity: EC number.
  • Shared function annotation: GO terms, compared by IC-weighted Ochiai similarity.
  • Shared pathways: KEGG maps.
  • Literature: QuickGO evidence codes, plus PubMed-verified curated findings.
  • Perturbation: mutant and genetic-interaction phenotypes.
  • Module profile and network role: the pair's places in their own networks.
  • Homology (supporting evidence only), checked through STRING reciprocal best hits, KEGG Orthology, PANTHER, Pfam, InterPro and frequent common folds.

Scoring. A pair's score is the weighted mean over the components that are available, so missing evidence never counts as negative. Categories follow fixed rules. A pair is called a candidate analogue only when it has no homology signal at any level and shares catalytic activity with independent support.

Robustness and evaluation. The ranking is re-run under Dirichlet weight perturbation, leave-one-component-out, three similarity measures, STRING thresholds from 0.4 to 0.9, and different random seeds. Alignment uses IsoRank with a degree-preserving rewired null. NetMF embeddings are tested against neighbourhood baselines on held-out edges, within each species only.

Sparsity reflects seed-set size, not poor connectivity. The bacterial seed sets have more edges than 97.7 % (oxidative stress) and 95.3 % (DNA repair) of random human subsets of the same size. A KEGG-Orthology-projected bacterial network adds only 11 proteins (oxidative stress) and 1 protein (DNA repair), so orthology cannot close the coverage gap.

Oxidative-stress defence

The human network has an antioxidant module of 69 proteins (SOD1–3, CAT, PRDX1–6, GPX2–8, TXNRD1–3, glutathione enzymes, NFE2L2/KEAP1). Both non-trivial bacterial modules match this module best. The bacterial network itself is small, with 11 edges.

The best-supported bacterial protein is peroxiredoxin Q (DR0846), which tops the ranking against human PRDX1–5. A double DR0846/DR1998 deletion is less stress-tolerant than either single mutant. Its pairs with human glutathione peroxidases are classed as distant_homolog: the only shared signature is the thioredoxin fold, so they are related peroxidases rather than analogues.

The sodA evidence is mixed

sodA insertion mutants are more radiation-sensitive than the wild type. Yet ΔMnSOD mutants survive gamma radiation better than the wild type, while becoming sensitive to oxygen during desiccation. The authors attribute this to small-molecule Mn antioxidants that supplant MnSOD. In D. radiodurans, part of the functional counterpart of human enzymatic SOD may therefore not be a protein at all, and a protein network cannot represent it.

DNA repair

The bacterial network divides into recognisable repair pathways:

  • base-excision repair (FDR 3 × 10⁻⁴);
  • RecFOR recombination;
  • nucleotide-excision repair (UvrABC);
  • replication and mismatch repair;
  • a Deinococcus-specific radiation-response module (recA, lexA, ddrA, ddrB, pprA).

Module correspondence with the human network is weakly discriminating: several bacterial modules match the human base-excision module best, so shared generic repair terms dominate the comparison.

Individual ranks move under these perturbations, especially in DNA repair, where the top of the list is dominated by orthologs. Each pair's 5–95 % rank interval is reported in candidates/candidate_pairs_all.tsv. The analogue category is best read as "pairs worth examining", not as a fixed set.

Limitations

  • Seed sets are GO-defined, and annotation depth differs strongly between the organisms. Most bacterial GO evidence is electronic or phylogenetic.
  • Curated literature covers 12 bacterial proteins at abstract level from targeted searches. Human perturbation evidence comes only from GO evidence codes.
  • "No detected homology" cannot exclude very remote homology. Broad EC numbers, such as EC 2.7.7.7 for all DNA polymerases, inflate some weak analogues.
  • STRING edges are functional associations, partly transferred between species through orthology. No bacterial physical-interaction data exist.
  • There is no ground truth for cross-species analogy, so no accuracy is claimed.
  • Non-protein defences, such as Mn²⁺–metabolite antioxidants, are outside the networks.
  • The research plan 2026-Graph-AnanthapadmanabhanDS was not available during development, so the design follows the written project brief.

Proposed experiments

  1. Convergent glycosylases. Complement a D. radiodurans mutM deletion with human OGG1, and an nth deletion with NEIL1, then measure 8-oxoG removal and survival after oxidative or ionising damage.
  2. Cross-family SOD complementation. Complement sodA with human SOD1 or SOD3 under H₂O₂, paraquat and desiccation. The mixed sodA evidence makes the choice of condition critical.
  3. OsmC activity. Assay DR1538 for hydroperoxide reduction to resolve its comparison with GPX7/GPX8.
  4. Deinococcus-specific repair factors. Characterise PprA, DdrA and DdrB against human end-processing proteins. The current data support no human counterpart for PprA.

Reproducing the analysis

From the repository root, with Python 3.11 and the pinned requirements installed. Runs read the cached raw data and verify every checksum first.

python -m extremonet --config config/phase1_oxidative_stress.yaml
python -m extremonet.analysis --config config/phase2_analysis.yaml
python -m extremonet --config config/phase1_dna_repair.yaml
python -m extremonet.analysis --config config/phase2_dna_repair.yaml
python -m pytest
